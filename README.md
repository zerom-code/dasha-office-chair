# Даша на колёсиках

PWA-игра для iPhone: 12 уровней, управление двумя ногами, награды и одежда.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи в него **содержимое этой папки**. `index.html` должен лежать в корне репозитория.
2. Открой **Settings → Pages**. В **Build and deployment** выбери **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажми **Save**.
3. Дождись ссылки в разделе Pages и открой её на iPhone. Адрес будет вида `https://имя.github.io/репозиторий/`.

Сборка, npm-зависимости и серверная часть не нужны. Пустой `.nojekyll` оставь в репозитории. Если выбранная ветка называется иначе, укажи её вместо main.

Для установки на iPhone: Safari → «Поделиться» → «На экран Домой». После первого открытия по HTTPS работает офлайн.

## Игра

Одна нога — толчок с поворотом. Коротко обе — прямо. Держи обе — тормоз. В круге цели нужно остановиться.

В интерфейсе нет прокрутки и выделения текста. Двойные касания и жесты масштабирования блокируются. Крестик описания уровня возвращает на экран, откуда уровень был открыт.

Прогресс и одежда сохраняются в этом браузере для адреса игры. У GitHub Pages будет своё сохранение: данные другого домена автоматически не переносятся. Кэш и сохранения разделены по пути репозитория, поэтому копии игры на одном GitHub-домене не мешают друг другу.

## Файлы

- `index.html` — экраны и кнопки.
- `v2/style.css` — оформление.
- `v2/app-2.0.1.js` — интерфейс, звук и сохранение.
- `v2/engine.js` — управление, физика, уровни и планировки офиса.
- `v2/render.js` — офис и Даша.
- `v2/customization.js` — одежда и награды.
- `v2/content.js` — записка после 12-го уровня.
- `v2/touch-guard.js` — обработка касаний и блокировка масштабирования.
- `sw.js`, `manifest.webmanifest`, `assets/` — установка и офлайн-режим.

Все пути относительные: работает и в подпапке репозитория, и на собственном домене.

## Локально

При установленном Python: `python3 -m http.server 4173`. На компьютере отображается приглашение открыть игру на iPhone.

Проверки физики и наград при установленном Node.js: `npm test`. Устанавливать пакеты не нужно.

## Обновления

После изменений загрузи новые файлы в ту же ветку. Если меняешь код интерфейса, используй новое имя основного JS-файла и обнови ссылку в `index.html` и список `ASSETS` в `sw.js`. Номер `VERSION` в `sw.js` и строка ожидаемой версии в основном JS должны совпадать. Это позволяет получить новое обновление даже после сохранения старой офлайн-копии.
