# Даша на колёсиках

Небольшая игра об офисе, кресле и рабочем дне Даши. 16 уровней, одежда за прохождение, сохранение прогресса и установка на iPhone и Android. Работает в браузере и офлайн после первого открытия.

## Уровни

- 1–12: поездки по офису, доставка кофе и документов, маршруты и парковка.
- 13: маршрут на время. Поражение сопровождается падением Даши и опрокидыванием кресла.
- 14: ходьба, первый звонок, посадка в кресло и возвращение к пешему управлению.
- 15: звонок, поездка, выход на перекур возле Держпрома и возвращение в офис.
- 16: смена с 9:00 до 17:00 — 12 реальных минут. Звонки и документы чередуются с поездками и перерывами. Посетители задают вопросы и прерывают работу; полиция приезжает к окнам. Для победы все дела должны быть закончены к 17:00.

Офис нарисован по фото и видео: плитка, жалюзи, принтер, контейнеры, стол с канцтоварами и коврик winter time. Улица — стилизованный квартал с Держпромом, офисом, сквером и дорожками между тротуарами. Расстояния адаптированы для игры.

## Управление

На кресле: одна нога даёт толчок с поворотом, короткое нажатие обеих — движение прямо, удержание обеих — торможение. Для парковки нужна остановка в круге.

Пешком: джойстик и кнопка действия рядом с телефоном, креслом, дверью или местом перерыва. Звонки и работа требуют нескольких секунд на месте. Ответ посетителю возобновляет прерванное дело.

На компьютере: стрелки или WASD для ходьбы; A/D или стрелки влево/вправо для ног, W или стрелка вверх для обеих ног; E или пробел для действия.

Пауза останавливает таймер. Место, текущие дела, оставленное кресло и прогресс смены сохраняются в этом браузере. Сохранения прошлых версий совместимы. Копии игры в разных подпапках имеют отдельные сохранения и кэш.

## Разработка

Игра использует HTML, CSS и Canvas без сборки и внешних библиотек.

```sh
npm run dev
npm test
```

Локальный адрес: `http://localhost:4173`. Для запуска сервера нужен Python 3, для тестов — Node.js 20 или новее.

| Файл                                       | Назначение                                   |
| ------------------------------------------ | -------------------------------------------- |
| `index.html`, `v3/style.css`               | Экраны и мобильный интерфейс                 |
| `v3/app-3.0.1.js`                          | Управление, звук, сохранения, обновление PWA |
| `v3/engine.js`                             | Физика, уровни и состояние игры              |
| `v3/geometry.js`                           | Физические основания мебели без теней        |
| `v3/workday.js`                            | Рабочие задачи, посетители, полиция и улица  |
| `v3/render-3.0.1.js`                       | Офис, персонажи, падение и район Держпрома   |
| `v3/customization.js`                      | Одежда и награды за все 16 уровней           |
| `sw.js`, `manifest.webmanifest`, `assets/` | Установка и офлайн-режим                     |

## Размещение

Поддерживается GitHub Pages: ветка `main`, каталог `/`. Все пути относительные, поэтому игра работает в подпапке репозитория и на собственном домене. PWA требует HTTPS или localhost. На iPhone установка доступна через меню Safari «Поделиться», на Android — через меню браузера.

Модули этой версии размещены в `v3/`: это позволяет загрузить их, даже когда предыдущий service worker ещё обслуживает старый кэш `v2/`. Версия кэша в `sw.js` соответствует ожидаемой версии в основном модуле. Список `ASSETS` включает все файлы для работы без сети. Сохранения используются совместно со старой версией.
